# フラクタル散歩

フラクタル空間をあなたがどこまでも心の許す限り探索できます。
あなたが見る世界は、どれも全方向に果てしなく続き、どこまでも縮んで奥へ入っていけます。

あなたが途中で辞めても、ずっと浸っても、この世界はあなたしかいません。どうぞごゆっくり探索ください。

ジャンプスケア、クリーチャーなどは一切出てきません。

出てくるのは構造物のみ。

## 遊び方

* **移動**：WASD（スマホは左下のスティック）
* **見回す**：マウスを動かす（クリックでカーソル固定、Escで解除）／スマホはドラッグ
* **ジャンプ・上昇**：Space
* **F**：飛行の切り替え
* **G**：自動サイズ（壁に近づくと縮み、離れると育つ）
* **Q / E**：縮む／育つ
* **O**：設定（重力の強さ、ジャンプの高さ、落下から飛行への切り替え時間、視点の上下制限、感度）
* **1〜9**：世界の切り替え
